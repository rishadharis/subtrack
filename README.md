# Subtrack

Pelacak langganan digital pribadi — ringan, cepat, sepenuhnya lokal. Data disimpan di file .subtrack milik Anda.

**Prinsip:** secepat mungkin, seringan mungkin.

## Quick start

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview build
- `npm run check` — type check

## Stack

- Svelte 5 + TypeScript
- Vite + Tailwind CSS v4
- PWA (vite-plugin-pwa)

MVP scaffolding only. UI and features added in later tasks.
